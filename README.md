# YouTube Userscripts

A collection of userscripts for YouTube. Works with [Tampermonkey](https://www.tampermonkey.net/), Violentmonkey, or any userscript manager.

## Scripts

| Script | Description |
| --- | --- |
| [YouTube Default Speed](scripts/youtube-default-speed.user.js) | Sets playback speed to 1.30x on regular videos. Skips YouTube Music and live streams. |

## Install

1. Install a userscript manager extension (e.g. Tampermonkey).
2. Open the script file above, click **Raw**, and your manager will offer to install it.
   Or create a new script in the manager and paste the contents in.
